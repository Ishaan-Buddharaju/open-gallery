Modules vs Packages: 
* Modules are the larger unit to version multiple compiled packages. 
* We publish and fetch modules not packages.
* Packages are the folders within a module that are compiled as seperate components that are linked to create the compiled build of the project.
* Go mod init created the main module which resolves dependencies of the packages beneeth it.
